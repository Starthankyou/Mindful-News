Mindful-News

真實資訊 × 靜心閱讀 × 心靈修煉 × 英文學習

專案簡介

Mindful-News 是一個「資訊選讀」的網頁／App 原型。
目標是每天提供一張由人工精選的世界資訊卡，結合：

真實且經查證的資訊

靜心、不焦慮的閱讀節奏

心靈與價值觀的反思引導

英文單字、文法與理解練習

使用者每天打開，只面對一則選讀好的內容，而不是無止境的演算法資訊流。

產品定位（一句話）

一款以「真實資訊 × 靜心閱讀 × 心靈修煉 × 英文學習」為核心的資訊選讀 App 與網站，
讓使用者在每日精挑的世界片段裡，保持清明、養成反思，並以微行動回應世界。

MVP 功能範圍（本版預計實作）
1. 首頁：今日資訊卡（Daily Card）

今日金句（英文＋中文）

精要摘要（5 點亮點式重點）

精選段落（中英對照的 2–5 個段落，內容先以假資料或 JSON 模擬）

英文學習區（關鍵單字＋文法亮點＋1～3 題理解題，先用靜態內容）

反思區

一句：今日啟發

一題：生活應用題

微行動區

系統提供一個行動建議

使用者可寫下「今日我能做什麼」

MVP 階段：資料可先寫死在檔案或簡單 JSON，不做後端。

2. 我的區塊（My Space）

收藏

收藏整張資訊卡

收藏金句

收藏行動建議

我的日誌（簡化版）

顯示使用者在「今日啟發」與「今日我能做什麼」欄位的歷史紀錄

隨機回顧

從過去的啟發句與金句中隨機抽一則顯示

MVP 階段：資料儲存在 LocalStorage。

3. 自訂輸入（簡易版）

使用者可以貼上一個網址（先不實作自動擷取，只儲存網址＋自訂標題）

顯示在「我的自訂來源」清單中，之後可擴充成完整的自訂資訊卡流程。

未來擴充（非本版 MVP）

自動擷取網站內容並生成：摘要、金句、反思題、微行動

使用者互相分享選讀卡、評分與標記（已查證／很有啟發／生活應用等）

資訊卡組裝成「一週／一月主題選讀集」

行動統計與個人成長儀表板

開發技術（暫定建議）

這部份可以給 Vibe Coding 協助你具體化與 scaffold：

前端框架：React + Vite + TypeScript

樣式：Tailwind CSS

狀態管理：以 React hooks＋簡單 context 為主即可

資料儲存：瀏覽器 LocalStorage（之後可換成 backend 或 Supabase）

部署：GitHub Pages（以 vite + gh-pages 或 GitHub Actions 發佈）
